Outline pill for categories, service subtitles and meta labels (e.g. "Shopify", "Audits", "Analytics", "13 min read").

```jsx
<Tag>Technical SEO</Tag>
<Tag variant="accent">GEO</Tag>
<Tag icon="Clock">17 min read</Tag>
```

- Always an outline pill: 1px border, 13px/500 text. On white/cream → white fill, #E8E2D8 border, gray text; on dark → #121212 fill, #262626 border.
- **Tags are never gradient.** The gradient is only for buttons, the NEW badge and CTA block B.
- `accent` swaps the text to orange — use it for the one tag that matters on a card (e.g. GEO, blog category).
